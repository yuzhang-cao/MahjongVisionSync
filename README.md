# MahjongVisionSync

基于多路视频分区感知的麻将赛事牌局状态识别、观众数据展示与复盘系统。

本项目面向赛事工作人员、裁判、转播数据人员和观众，不面向参赛选手提供实时决策建议。系统目标不是单纯实现麻将牌面识别，而是把多路比赛视频或多台采集设备产生的识别结果转换为结构化牌局事件，用于赛事记录、直播数据展示、裁判辅助和赛后复盘。

当前代码来自 `MahjongTing`，已经具备单机麻将手牌录入、听牌/胡牌计算、相机扫描和 CoreML 牌面识别基础。后续毕设扩展重点是把这些基础能力接入比赛场景下的多路视频分区输入、识别事件化、牌局状态重建、概率趋势展示和复盘记录系统。

> Xcode 工程和 App Target 暂保留 `MahjongTing` 命名，避免在迁移阶段引入工程引用风险。仓库展示名称建议使用 `MahjongVisionSync`。

支持广东 / 四川规则，支持手动录入、听牌与胡牌计算、碰 / 杠管理，以及相机扫描识别。

## 当前内容

- 规则计算：广东、四川；支持七对；广东支持十三幺；四川支持定缺
- 手牌操作：图形化点牌、删牌、清空、碰、杠、暗杠、明杠
- 扫描入口：AVCapture 相机扫描页面，接入 CoreML 整排识别
- 测试工具：开发期数据集导出代码已移到根目录 `TestCode.swift`

## 赛事系统定位

- 多路输入：优先支持四路选手手牌区视频，弃牌区作为可选视频、人工录入或校正输入。
- 数据用途：面向赛事记录、裁判核验、转播展示和赛后复盘。
- 展示对象：赛事工作人员、转播数据人员和观众，比赛选手不接收实时决策信息。
- 技术重点：视频分区感知、识别事件同步、牌局状态重建、合法性校验和数据可视化。

## 项目结构

- `App.swift`：应用入口与方向控制
- `MainView.swift`：主界面与交互
- `ViewModel.swift`：手牌状态与计算调度
- `Engine.swift`：听牌 / 胡牌 / 副露计算
- `ScanView.swift`、`Camera.swift`、`CameraPreview.swift`：扫描界面与相机采集
- `Recognizer.swift`：CoreML 识别
- `TestCode.swift`：开发 / 测试期工具，不参与 App 运行逻辑

## 后续改进

- 多路视频输入：支持公开比赛视频切流、固定机位视频和后续 iOS 实时采集
- 识别事件化：把每路手牌区或弃牌区结果封装为带时间戳、区域和置信度的事件
- 状态重建：将手牌、弃牌、副露、已见牌统一建模并校验合法性
- 展示分析：为工作人员和观众展示听牌、有效牌、剩余有效牌和趋势快照
- 复盘记录：保存关键事件、人工确认和状态快照，支持赛后回放
